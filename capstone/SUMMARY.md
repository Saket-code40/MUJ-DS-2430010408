## Project: Customer Churn Prediction

### Objective
Build an educational Deep Learning model to predict telecom customer churn while demonstrating fundamental ML/DL concepts.

### Key Deliverables
- Neural network with dropout, L1, L2 regularization experiments
- 5-Fold Cross-Validation
- Bias/Variance demonstration
- Early stopping analysis
- 9 publication-quality graphs
- Comprehensive documentation + presentation

### Technologies Used
Python, TensorFlow/Keras, scikit-learn, pandas, matplotlib, seaborn

### Results Summary
- Best model: Logistic Regression (F1 = 0.5692)
- Best NN variant: Dropout 0.3 (F1 = 0.5524)
- Model stability confirmed via CV (F1 std = 0.021)
- Early stopping triggered at epoch 14 (best epoch 6)
